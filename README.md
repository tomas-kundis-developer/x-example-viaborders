Via Borders
===========

<!--suppress CheckImageSize -->
<img alt="Hexagonal architecture picture" src="./docs/assets/route-path.jpeg" width="200" height="200"/>

Via Borders is the service that find route from origin to destination country.

Country map is based on this resource:
https://raw.githubusercontent.com/mledoze/countries/master/countries.json

> The algorithm will find the one of many shortest routes, if more than one shortest
> path exists.

> Service is based on **Dijkstra's algorithm** for finding the shortest path. \
> It uses heap (priority queue) for optimization.

How To Build and Launch Service
===============================

## Quick Service Start

> Quick start with *Spring Boot Maven Plugin*.\
> Suitable for a development and test mode.

Start application with `spring-boot:run`:

```shell
$ cd <project-dir>
$ mvn clean
$ mvn spring-boot:run
```

### More Info

Official
documentation: [Running your Application with Maven](https://docs.spring.io/spring-boot/maven-plugin/run.html)\
*Spring Boot / Build Tool Plugins / Maven Plugin / Running your Application with Maven*

Local [HELP.md](./HELP.md) file generated by [Spring Initializr](https://start.spring.io/).

## Build `jar` Artifact

Also runs unit and integration tests.

```shell
$ cd <project-dir>
$ mvn clean
$ mvn install
```

Built artifact will be located in project's `target` directory:

`<project-dir>/target/viaborders-<version>.jar`

or in localhost's local Maven repository on localhost:

`<.m2>/repository/org/tomo/examples/viaborders/<version>/viaborders-<version>.jar`

---

* `<version>` is artifact's `version` defined in `pom.xml`
* Maven `.m2` directory on Windows, macOS and Linux is usually located in: `<user>/.m2/`
